Ключ Anthropic API

Приложению нужен ваш собственный ключ Anthropic API, чтобы генерировать тексты. Он сохраняется только в этом браузере и отправляется исключительно на ваш сервер вместе с запросом — учителю не нужно ничего настраивать на сервере.

Получить ключ на console.anthropic.com →

Как это работает

1) Вкладка «Формативка» — опишите предмет, класс и тему, нажмите «Сгенерировать». Скачайте готовый документ в .docx и распечатайте.

2) Вкладка «Анализ оценок» — вставьте таблицу или загрузите файл (ученик / задания / оценки), нажмите «Проанализировать». ИИ покажет, над чем поработать каждому ученику и какие темы стоит повторить всему классу.

Тексты создаёт модель Claude по вашему собственному ключу Anthropic API — он не хранится на сервере.
